### 🚀 About Me

I am a passionate **Software Engineer** at **Zone 01 Kisumu**, driven by creating robust backend systems, intuitive digital platforms, and scalable web applications.

- 🔭 **Current Focus:** Leading development on [**LejaSmart**](https://github.com/luiwere) — an intelligent financial tracking platform empowering businesses with automated P&L statements, predictive financial forecasting, and cash flow insights.
- 🌱 **Leveling Up:** Deepening mastery in **Go (Golang)**, **Java & Spring Boot**, and **React** for enterprise-grade distributed systems.
- 💡 **Core Interests:** Scalable System Architecture, FinTech solutions, API design, and Database Optimization.
- 👯 **Collaboration:** Actively looking to contribute to high-impact **Open Source** projects.
- ⚡ **Fun Fact:** I love turning complex business logic into clean, self-documenting code.
